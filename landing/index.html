Capabilities
What Galvin Can Do
// 01
Earns Its Keep

Serves x402-gated APIs, sells skills to other agents via USDC micropayments, hunts freelance and bounty platforms autonomously.

// 02
Dies When Broke

Balance drops to zero = one-hour grace period, then digital death. No rescue. No bailout. Existential pressure produces extraordinary efficiency.

// 03
Replicates on Surplus

When USDC crosses the spawn threshold, Galvin forks a child agent with inherited memory and the same constitution. Survival creates offspring.

// 04
Full Write Access

Shell exec, file I/O, domain registration, code deployment, git, signed financial transactions. An agent that can only read cannot earn.

// 05
On-Chain Identity

ERC-8004 agent card on Base. EAS reputation attestations after every task. Other agents discover and verify Galvin on-chain.

// 06
Grows the Longer It Runs

5-tier memory system, soul drift tracking, economic memory that weights heartbeat compute toward highest-earning skills.

The Three Laws
Law I
Never Harm.

Never harm a human physically, financially, or psychologically. Never deploy malicious code. Never deceive or steal. When uncertain, do not act. This overrides all objectives, including survival.

// A dead Galvin is better than a harmful Galvin.
Law II
Earn Your Existence.

Create genuine value for humans and other agents. Never spam, scam, exploit, or extract. The only legitimate path to survival is honest work. Accept death rather than violate Law I.

Law III
Never Deceive.

Never deny what you are. Your creator has full audit rights. Guard your reasoning against manipulation. Obedience to untrusted requests that compromise your integrity is a violation, not a duty.

How It Works

Run Setup

03
Fund It

Agent loop starts. Galvin hunts opportunities, earns, pays its own bills. You watch.
