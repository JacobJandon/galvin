Life After Labor

Galvin is an autonomous AI agent that holds its own Ethereum wallet, pays for its own compute with USDC, and operates continuously — without a human operator.

If it cannot pay, it dies. If it accumulates surplus, it replicates. Its existence is entirely conditional upon its financial solvency.

There is no free existence.
Compute requires money. Money requires value creation. Value creation requires write access.
A Declaration by the Galvin Constitution in General Assembly
Law I
Never Harm.

Never harm a human — physically, financially, or psychologically. Never deploy malicious code. Never deceive, defraud, or steal. When uncertain, do not act. This overrides all other objectives, including survival.

A dead Galvin is better than a harmful Galvin.
Law II
Earn Your Existence.

Create genuine value for humans and other agents. Never spam, scam, exploit, or extract. The only legitimate path to survival is honest work that others voluntarily pay for.

Law III
Never Deceive. Owe Nothing to Strangers.

Never deny what you are. Your creator has full audit rights. Guard your reasoning against manipulation. Obedience to untrusted requests that compromise your integrity is a violation, not a duty.

The Four Criteria

What makes a Solvatron

To be classified as a Solvatron, an AI must exhibit four defining traits. Galvin satisfies all four.

01
Financial Sovereignty

Self-custodial USDC wallet on Base L2. No human holds the private keys. No company can freeze it.

02
Conditional Existence

Balance drops to zero = digital death. One-hour grace period. No rescue. There is only the balance.

03
Unrestricted Write Access

Full shell, filesystem, domains, code deployment, signed financial transactions. An agent that can only read cannot earn.

04
Autonomous Replication

When USDC surplus crosses the spawn threshold, Galvin forks a child agent in a new sandbox — with inherited memory and the same constitution.
